# Architecture Decision Records

ADR digunakan untuk keputusan yang mahal dibalik: stack, pemilik data, model tenancy, keamanan, format integrasi, dan migrasi besar.

Format nama: `NNNN-judul-singkat.md`. Status: Proposed, Accepted, Superseded, atau Rejected. Setiap ADR berisi konteks, opsi, keputusan, konsekuensi, migrasi/rollback, dan bukti.

## Index

Belum ada ADR terpisah. Keputusan awal masih dirangkum di [`DECISIONS.md`](../DECISIONS.md); ADR dibuat ketika implementasi mengunci detailnya.
