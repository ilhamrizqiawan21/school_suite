# School Suite · Calm Academic 2026

Mockup dibuat di FigCraft. Buka `school-suite-calm-academic.figcraft` untuk meninjau layer yang dapat diedit dan prototype.

Untuk meninjau semua preview tanpa FigCraft, buka [index.html](index.html) di browser.

## Delapan artboard

1. Dashboard desktop: prioritas, agenda, ringkasan, tren, dan pengumuman.
2. Data siswa desktop: breadcrumb, submenu, pencarian, filter, ekspor, serta aksi edit/hapus berikon.
3. Edit siswa desktop: drawer kontekstual dengan latar redup, tab, field, dan footer aksi.
4. Landing sekolah desktop: identitas, hero, keunggulan, kehidupan sekolah, SPMB, dan kontak.
5. Data siswa mobile: daftar berbentuk kartu, target aksi 44 px, dan contoh toast sukses.
6. Edit siswa mobile: sheet satu kolom dan footer simpan.
7. Landing sekolah mobile: susunan vertikal yang menjaga keterbacaan.
8. Sistem komponen: palet, ikon aksi, toast sukses/gagal, konfirmasi hapus, dan empty state.

## Menjalankan prototype FigCraft

Pilih flow pada mode Present. Dari dashboard, klik Akademik atau prioritas identitas siswa untuk membuka direktori. Klik pensil untuk melihat drawer edit; tombol tutup/simpan mengembalikan tampilan daftar. Pada flow mobile, pensil membuka sheet dan tutup/simpan kembali ke daftar.

Ini prototype visual: field, export, pencarian, filter, dan penghapusan belum menjalankan operasi data. Drawer desktop ditampilkan sebagai artboard state lengkap. Versi desktop dan mobile merupakan artboard terpisah, bukan bukti pengujian responsive aplikasi produksi.

Nama sekolah, statistik, identitas siswa, akreditasi, tanggal, dan kontak adalah data ilustrasi. Foto memakai aset ilustrasi yang sudah tersedia di proyek; keaslian dokumentasi sekolah belum diverifikasi.

## Keputusan visual

Inter untuk UI; academic blue lembut, latar abu kebiruan, panel putih, status sage/amber/rose. Tombol aksi menggunakan ikon tanpa teks; label dan tooltip perlu dipasang saat implementasi. Sidebar mengelompokkan ruang kerja dan menunjukkan turunan Akademik. Semua artboard dan preview disimpan bersama untuk review.
