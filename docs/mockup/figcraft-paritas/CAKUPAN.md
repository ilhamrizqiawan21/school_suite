# Peta requirements ke artboard

Target 100% berlaku untuk kemampuan produk. Pemetaan seluruh ID yang terdaftar menunjukkan bahwa setiap requirement punya rujukan visual. Paritas baru terverifikasi setelah inventaris per peran lengkap, setiap temuan tercermin pada layar dan interaksi yang terkait, dan hasilnya lulus uji.

Layar tambahan dari REA mencakup [filter pelacakan](index.html#FILTER-TRACK) untuk TU-04, [kontrol kios](index.html#KONTROL-KIOS) untuk OPS-03, [akses pos](index.html#AKSES-POS) untuk OPS-04, serta [editor RAB](index.html#EDITOR-RAB) dan [status proposal](index.html#STATUS-PROPOSAL) untuk INT-01 dan INT-02.

Buka tautan untuk langsung meninjau layar pada pratinjau. Referensi mencakup seluruh 48 ID requirements. Referensi FND dan REL menunjukkan layar yang terkena dampak. Otorisasi server, antrean, migrasi, pemulihan, serta UAT tetap dibuktikan dengan implementasi dan pengujian sesuai requirements.
